View Modes

Режимы отображения 3D-вьюпорта. Помогают оценить варианты визуализации модели.

01Wireframe
Только рёбра, без заливки. Скрытые линии — пунктиром.
02Shaded
PBR-материал, без overlay рёбер. Для презентаций.
03Shaded + Edges
Заливка + чёрные рёбра. По умолчанию для моделирования.
04Direct Modeling
Гизмо Move/Rotate на выбранной грани + панель параметров
05Drawing Mode
2D лист с видами (Top/Front/Right/Iso), размерами, BOM-балунами, title block
