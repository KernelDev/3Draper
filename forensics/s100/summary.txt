THE 3 REFUTED PLACEMENTS (design iterations, kept for the record)
------------------------------------------------------------------
1. Single-phase PRE-WINDING: fired on TRANSIENT anti-wound seams that
   fix_inconsistent_winding harmonizes by itself (the drill f6 x f265
   rim zipper: 6+ cascade splits, one per zipper edge; DRILL_SHAFT
   pairs) => 2-phase design (record pre-winding, split only survivors).
2. Phase 2 PRE-v5 (post-flapclean): fired on pairs the v5 audit
   RESOLVES by flipping one side (4 extra HOUSING splits on
   census-invisible pairs; the splits rippled the v5 component graph,
   +1 manufactured sub-tol pair) => phase 2 moved AFTER the v5 audit
   (the last winding-touching stage).
3. Fat anchor via thickness (2*area/shortest, the s89 measure): fired
   on 4+ HOUSING pairs the census classifies sub-tol (thin lips whose
   shortest NON-shared edge is tiny inflates the measure) => aligned to
   the probe's apex-height-over-shared-edge rule.

LESSONS
-------
1. Stage-aware placement: a pass that acts on winding-adjacent state
   must run AFTER every stage that could resolve or manufacture the
   target class (winding BFS harmonizes transients; the v5 fixpoint
   flips resolvable pairs) — else it either steals transients or gets
   rippled by downstream flips.
2. Measure alignment is not optional: the census's sub-tol rule is
   apex-height-over-shared-edge; the s89 flapclean's ear rule is
   2*area/shortest. A gate using the wrong measure fires on the other
   pass's territory (measured: 4 spurious splits + v5 ripple).
3. A pure-topology split (vertex clone, face-scoped) is the minimal
   never-worsen action for born-folded seams: flips are blocked by
   ripple trades (s99), removals open sub-resolution gaps, clipping is
   heavy machinery. The flap remains as a sealed zero-gap double ply —
   sim-irrelevant at 2e-5 lens scale.
4. Every exempt class of the diagnostic census that production now
   touches must be replicated in the production gate (the s94 knife-fin
   pinch: without it, 4 exempt SPRING pairs unwelded + 2 new BUG lines).

THE 3 REFUTED APPROACHES for item 2 (measured, kept for the record):
1. MERGE FOLD GUARD at the weld site (mesh.rs, default-ON weld refusal):
   the fold-preview CANNOT work at the merge — (a) a half-resolution
   preview sees false folds on cascading lattice welds (fid=51 d=0.0118
   lattice: dozens of spurious refusals); (b) a full-resolution preview

   on lattice folds that fix_inconsistent_winding removes later (usage
   >= 3 there). The discrimination knowledge (transient vs surviving)
   lives ONLY at the end of the pipeline — the 2-phase design already
   has it. REVERTED (mesh.rs back to HEAD).

   discriminator — the (3,3) dup apexes are 0.14 APART (the census's
   COINCIDENT flag is d01/d10 < 1e-6 coplanarity, not apex distance),

3. Coplanarity (d01/d10 < 1e-6) exclusion: also wrong — a 180-deg fold
   IS coplanar by definition; it caught (62,62) (180.00 exact).
   The planar-face exclusion is the correct discriminator.
